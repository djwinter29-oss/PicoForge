# Pico 2 SDIO 25 MHz qualification

## Scope

Pico 2 / RP2350, reported system clock 150 MHz, native 4-bit PIO SDIO,
configured/reported bus clock 25,000,000 Hz. Connected card capacity:
7,969,177,600 bytes (15,564,800 sectors). No CPU overclock, formatting,
CRC bypass, commit or push. This qualifies this board/card combination,
not every card, RP2040, CPU clock or long-duration workload. No oscilloscope
measurement of electrical setup/hold or actual CLK frequency was performed.

Backend: GitHub Copilot CLI investigation, coordinator hardware debugging,
final PIO correction and verification.

## Failure and correction

The falling-edge TX implementation, including the initial start-value-only
preload adjustment, initialized at 25 MHz but failed its first self-test
write with FatFs DISK_ERR (1), application error 8, written_bytes=0.
Temporary RAM instrumentation read through OpenOCD identified CMD24 data
response 0xB (CRC rejection). Instrumentation was removed before final tests.

CLK/CMD/DAT input_sync_bypass is already set by host initialization. At
150 MHz / 25 MHz, the clock half-period is only three system cycles. Updating
DAT after observing the falling edge leaves insufficient TX timing margin.
The fix preloads the start value while outputs are disabled, launches
start/data/end after rising edges, and lets the card sample on the next
rising edge. It preserves complete start and end bit sampling periods and
response/busy handling. RX, CRC/lane decoding, 64-sector FIFO count loading,
DMA completed-block checks and cancellation code are unchanged.

This timing diagnosis is supported by the CRC rejection and the focused
phase-change passing HIL, not by an electrical waveform capture.

## Final firmware results

All rates are decimal MB/s. Self-test writes a temporary file, reads it all
back and verifies its contents; timings are not bare-card throughput.

- 32 MiB: write 5,897 ms (5.690 MB/s), read 5,129 ms (6.542 MB/s).
- 128 MiB run 1: write 20,932 ms (6.412 MB/s), read 20,481 ms (6.553 MB/s).
- 128 MiB run 2: write 20,663 ms (6.496 MB/s), read 20,462 ms (6.559 MB/s).
- 128 MiB run 3: write 20,371 ms (6.589 MB/s), read 20,464 ms (6.559 MB/s).

Each completed run reported passed, exact target byte counts for writes and
reads, mismatch_count=0, error=0, filesystem_result=0, active=false,
file_remains=false and volume_mounted=false.

Cancellation during another 128 MiB write completed with state=cancelled,
written_bytes=1,114,112, read_bytes=0, error=0, filesystem_result=0,
active=false, file_remains=false, volume_mounted=false.
